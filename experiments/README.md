# NodeSeek auto AI 独立测试版

正式安装文件已恢复为 **1.4.74**。AI 仍在试验，未接入正式脚本的自动更新。

## 安装

1. 已安装 1.4.75 的用户，先通过[正式安装链接](https://raw.githubusercontent.com/wangjialiangsaa/NodeSeek_auto/main/NodeSeek%20Issue%20Templates.min.user.js)在油猴确认重新安装 1.4.74。版本降低不会触发通常的自动升级。
2. 在油猴中新建脚本，删除默认内容，完整复制 [NodeSeek-auto-AI-test.user.js](NodeSeek-auto-AI-test.user.js) 中的代码并保存。
3. 刷新 NodeSeek。此脚本可以单独使用，也可以与正式版 1.4.74 一起启用；名称、设置和请求独立。

## 配置与测试

在左下角 AI 小助手的齿轮，或右侧统计栏的 AI 图标中打开设置：

- **API 地址**：支持 Chat Completions 兼容接口，例如 `https://你的服务/v1` 或完整的 `https://你的服务/v1/chat/completions`。
- **API Key**：填写你所使用服务的密钥；localhost、127.0.0.1、IPv6 回环地址的本机接口可留空。远程接口使用 HTTPS。
- **模型名称**：使用服务实际提供的名称。
- **思考等级**：默认由模型决定，不发送 `reasoning_effort` 参数。也可选择 none、minimal、low、medium、high、xhigh；具体支持哪些值取决于模型和服务。

点击 **测试连接** 会直接使用表单里当前填写的地址、Key、模型和思考等级，发送一条简短的真实请求；无需先保存或启用，也不会发送论坛内容。看到成功后，再保存设置并启用助手。请求可能产生服务商的 API 费用。

测试成功仅表示这套配置当时能返回有效文本。若提示思考参数或请求不兼容，先改为默认等级后重试；若默认成功，再逐级测试该模型支持的值。界面提供取消、超时与 HTTP 错误提示，不显示密钥或原始错误响应。

## 本版可测试的功能

- **总结本页**：帖子页总结已加载的主帖和回复；首页和分类页整理已加载的帖子标题。
- **重复问题**：根据当前页面材料归类疑似重复问题，列出可参考的原帖链接。
- **问题补充**：可输入希望重点整理的问题。
- **复制与取消**：结果可复制；请求可取消；切换页面后忽略旧回复。
- **独立设置**：与正式版共用页面颜色，左下角可折叠，避让固定回复栏。

不会自动调用 AI，也不会自动发帖或回复。只在你点击总结或重复问题时发送当前已加载的公开材料，不读取私信和编辑草稿。当前版本不进行全站搜索，也不抓取未加载的帖子正文。Key 保存在油猴脚本存储中。

## 源码与构建

实验源码位于 `ai-assistant/`。使用 `node experiments/build-ai-test.cjs` 生成完整测试脚本；正式版 `tools/build.js` 不包含实验源码。

API 传输与错误处理通过本地模拟测试验证。仓库不包含真实 API Key，未替你验证任何实际服务的可用性。
