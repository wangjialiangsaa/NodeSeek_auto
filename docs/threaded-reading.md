# 楼中楼整合说明

1.4.51 将独立楼中楼脚本的阅读、分页和固定回复栏整合进现有脚本。源码位于 `src/threaded.js`，通过构建合并进可读版和压缩版；不需要安装第二个脚本。

当前版本 **1.4.67**。1.4.66 增加 Reddit 风格的分支布局：左侧层级细线、圆形加减按钮，以及各分支独立收起与展开；1.4.67 隐藏楼中楼右上角楼层编号，并支持设置默认折叠状态。

## 使用

- 在帖子评论区上方选择“楼中楼 / 引用 / 原始”。父评论已加载时点击回复对象即可定位，未加载时可以跳转原页或按需文字预览。
- 对话默认折叠，显示圆形加号及“另外 N 条回复”，点击可展开；展开后点击减号可收起全部后代，父评论正文和原生操作按钮保持可用。数量按实际父子关系统计，深层缩进达到显示上限后仍正确计数。
- 在“自动化 → 楼中楼默认折叠”取消勾选并保存可改为默认展开。修改立即应用当前页，后续打开的帖子与新出现的分支沿用选择；保存未改变的默认值不会重置手动状态。首次使用或旧设置没有该项时默认折叠。
- 分支可独立收起。收起再展开父分支时，子分支原先的收起状态会保留；新回复和续页加入后，继续遵循所属分支的状态并更新数量。
- 切换“引用 / 原始”暂时显示所有已加载评论，切回“楼中楼”恢复分支状态。定位新回复、“我的回复”或已加载的楼层链接时，先展开目标的祖先分支，再滚动定位。
- 下滑接近底部自动加载下一页，按楼层去重；新加载的回复会接到已有讨论下面。短页继续向后加载，到末页停止。请求失败不清空已有评论，稍后继续下滑重试。
- 底部“展开回复”打开原生编辑器，点击评论的回复、引用或编辑也会展开。收起保留草稿，发布仍由原生按钮完成。已有模板、计算器和功能设置弹窗可继续使用。
- 油猴“功能开关 → 楼中楼阅读”即时控制整个模块。关闭会取消分页请求、移除导入评论、恢复原始排列与分页、恢复编辑器位置，不清空原生编辑器草稿。

切换帖子页面或关闭功能时，会清理分支按钮、层级线和隐藏状态；新页面按保存的默认偏好初始化。楼层编号仅在楼中楼模式隐藏，原生编号节点与定位链接保留，引用和原始模式恢复显示。

## 范围

从第 N 页打开时继续加载第 N+1 页及其后续页，不预先下载之前的所有分页。已加载范围才参与排序和进度。原始模式保留自动续页和固定回复栏。

支持正文开头指向本帖更早楼层的 `#楼层` 回复头，也支持句中、句末及后续段落中相邻的站内 `@用户名 #楼层` 回复链接。1.4.55 修复了句末回复漏归组、多层回复断开，以及回复头被格式标签包裹时可能隐藏正文的问题。

1.4.56 根据实际页面补充识别未生成链接的 `@用户名`：它紧邻本帖更早楼层的链接，且用户名与已加载目标楼层的作者完全一致时，也会归入楼中楼。句末原文保持可见，切换原始模式恢复原排列。

普通 @、正文中单独提及的楼层、其他帖子、引用块与代码保持原有含义。没有明确开头回复头且同时指向不同回复对象时，不强行归组；回复主帖 #0 保持顶层。切回“原始”会恢复原回复链接和正文。

初始页保留原生节点及事件。导入页有完整可解析 JSON 数据与原生 Vue 菜单时复用原生菜单，否则提供可用的“引用 / 回复 / 原页操作”；后者打开原页进行点赞、加鸡腿等操作。远程页面里的脚本不会执行。

## 验证

`npm test` 包含楼中楼 DOM 回归测试、可读版与压缩版完整脚本的整合测试，以及图片上传、自动任务和配置库测试。楼中楼覆盖句末回复、多层关系、格式化正文保留、引用与代码排除，以及多层分支独立收起、完整后代计数、动态回复与续页状态、模式切换、定位展开和隐藏分支的连线处理。整合测试覆盖模板入口与原生编辑器共存、草稿保留、即时开关、跨页去重回复、发帖页布局；原生评论节点和事件处理器保留也纳入回归检查。

原生菜单复用使用模拟组件验证；站点版本改变时会回退为简化菜单。此前已核对真实 NodeSeek 的 DOM 与公开编辑器入口。本次 1.4.66 的 Reddit 风格样式依据参考截图实现，浏览器预览被权限限制阻止，仅进行截图参考和自动化验证，尚未完成本版本真实页面的视觉验收。不以发送真实评论作为测试。
