# [油猴脚本] NodeSeek auto：楼中楼、图片上传、自动签到、交易模板整合

给 NodeSeek 整合了一套日常使用的油猴增强工具，目前版本 **1.4.70**。在原交易模板基础上，加入主页自动续页、楼中楼阅读、图片粘贴上传、用户资料展示、内容过滤和自动任务等功能。

**主页自动续页**

- 默认开启，仅主页（`/` 或 `/page-N`）下滑接近列表底部时自动加载下一页，帖子去重，末页停止。
- 保持当前“新帖子 / 新评论”排序，新加载的帖子同样支持过滤和“已回复”标记。
- 保留上方手动分页入口，隐藏底部页码；加载失败保留已有列表，稍后继续下滑可重试。
- 可在油猴“功能开关 → 主页自动加载”关闭，关闭后恢复底部分页。

**阅读与回复**

- Reddit 风格楼中楼：左侧层级细线配圆形加减按钮。点击减号收起该分支的全部回复，保留父评论正文并显示回复数量；点击加号展开，多层分支可独立收起。
- 楼中楼隐藏右上角楼层编号，对话默认折叠。在「自动化 → 楼中楼默认折叠」取消勾选并保存，可改为默认展开，立即应用并记住选择。
- 新回复和下滑续页保留分支状态；可切换「楼中楼 / 引用 / 原始」，引用和原始模式显示全部评论，切回楼中楼恢复收起状态。原生回复与菜单按钮继续使用。
- 下滑自动加载：接近评论区底部时接入下一页，无需点击加载按钮，并去除重复的置顶评论。
- 自动加载的评论支持原生点赞、鸡腿等菜单；当前版本修复了论坛数据格式变化导致按钮缺失的问题，组件无法复用时可通过「原页操作」完成互动。
- 回复后保留之前自动加载的对话；若论坛刷新或跳到末页，同一标签页会恢复刚才的阅读范围与手动折叠状态，再定位新回复。恢复失败保留当前内容，下滑可重试。
- 底部固定回复栏：支持展开、收起和保留草稿，点击楼层的回复、引用可直接展开；按 **Ctrl + Enter** 展开并聚焦输入框，已展开时直接聚焦，收起按钮标注“展开回复 · Ctrl+Enter”。
- Ctrl + Enter 只展开和聚焦；回复栏仍为 **Enter 发送，Shift + Enter 换行**，中文输入法确认不会触发快捷键或误发送。
- 「我的回复」可查看并跳转自己回复过的楼层，列表页也会标记回复过的帖子。定位新回复、我的回复或楼层链接时，自动展开目标所在的分支。

**用户资料与过滤**

- 楼主、普通楼层和楼中楼昵称下，直接显示公开的等级、鸡腿、星辰、主题数、评论数和加入天数。
- 支持按关键词、用户昵称屏蔽或高亮列表中的帖子；隐藏后不保留占位提示条。
- 「过滤」与「自动化」位于个人信息统计栏底部，使用相同的图标尺寸和行距。

**图片上传**

- 使用官方 [NodeImage 图床](https://www.nodeimage.com/)。
- 在发帖、回复或私信编辑栏中 **Ctrl + V 粘贴截图 / 图片**，自动上传并在光标处插入 Markdown。
- 也可通过粉色「上传图片」按钮选择多张图片，支持查看进度和失败重试。
- 首次使用若提示未登录，先完成 NodeImage 授权，再回到编辑器重试。

**出鸡、收鸡与交易工具**

- 出鸡模板支持单机、多机、文本和表格 Markdown 格式；收鸡模板支持配置、预算、收购方式和交易标签。
- 支持机器配置库搜索与自动回填，出鸡模板可选择参与配置共建。
- 支持剩余价值计算、汇率换算和生成剩余价值卡片。
- 自己的交易帖可快捷切换「已出 / 不出了」或「已收 / 不收了」。
- 出鸡模板、图片上传、计算器和收鸡模板统一收进「🐔 工具」菜单，展开后保留各按钮的图标和颜色。

**自动任务与抽奖**

- 每日自动签到：默认开启，登录并打开 NodeSeek 时检查签到；关闭网页时不运行，可自行关闭。
- 抽奖帖自动回复：默认关闭。保存自定义语句并开启后，进入帖子时检测楼主正文中指向本帖、尚未到期的官方抽奖链接，自动发送保存的内容，无需点击抽奖链接。
- 已回复、自己发起的抽奖、有草稿或无法完成核实的帖子会跳过；不会自动遍历其它帖子。
- 发帖时可配置抽奖时间、中奖人数、起始楼层等，并生成官方抽奖链接与说明。
- 支持跟踪自己发起和参与的抽奖、查看中奖记录，并一键公布中奖名单。互动和回复条件需自行核对，中奖名单以官方抽奖结果为准。

界面跟随论坛浅色 / 深色主题切换，提供油猴功能开关，可按需启用。
